Ye sirf ek baar karna hai. Uske baad yahan se kapde, photo ya price badloge to website par apne aap badal jayega.

Token kaise banate hain
  1. GitHub kholo, apni profile photo dabao, phir Settings.
  2. Sabse neeche Developer settings, phir Personal access tokens, phir Fine-grained tokens, phir Generate new token.
  3. Name me rudra-admin likho. Expiration me sabse lamba time chuno.
  4. Repository access me Only select repositories chuno aur apna store repo chuno.
  5. Permissions, phir Repository permissions, phir Contents ko Read and write karo.
  6. Generate token dabao. Token copy karke neeche paste karo.

Ye token sirf is phone ke browser me rehta hai. Kisi ko mat dena. Kabhi bhi Disconnect dabake hata sakte ho.
